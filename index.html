TradingView alert setup

1. Άνοιξε TradingView και πρόσθεσε τον δείκτη ForexPilot Pine Script. 2. Δημιούργησε alert με condition “Any alert() function call”. 3. Για αποστολή στο app απαιτείται δικός μας HTTPS webhook server και push notification service — δεν υπάρχει ακόμη συνδεδεμένος server.

Safety

Μόνο demo/paper trading. Δεν στέλνονται πραγματικές εντολές. Τα σήματα είναι rule-based εκπαιδευτικές ενδείξεις, όχι AI προβλέψεις ή επενδυτικές συμβουλές. Forex/CFD με μόχλευση μπορεί να προκαλέσει γρήγορες απώλειες.
